# ⚡ EV Charging Infrastructure Analytics Dashboard (India)

## 📌 Project Overview

This project analyzes the **EV public charging station network in India** using a simulated dataset designed to reflect realistic infrastructure patterns and demand behavior.

The goal of this Tableau project is to provide an interactive, decision-support dashboard system for:

- Monitoring charging demand across states  
- Identifying high-utilization and capacity-stressed regions  
- Understanding charger type distribution (Fast vs Slow)  
- Supporting policy-driven infrastructure expansion planning  

This project is aligned with India's EV growth initiatives such as the **PM E-DRIVE Scheme**.

---

## 🎯 Objectives

- Provide a national overview of EV charging infrastructure
- Identify top demand states and high-pressure regions
- Monitor utilization trends and revenue performance
- Highlight overloaded stations and capacity constraints
- Build an internship-level Tableau dashboard portfolio project

---

## 📂 Dataset Details

- **Total Stations Simulated:** ~29,000  
- **Coverage:** All Indian States & UTs  
- **Charger Types:** Fast + Slow  
- **Key Metrics Included:**
  - Daily Charging Sessions
  - Utilization Percentage
  - Revenue Estimates
  - Charger Capacity
  - Demand Stress Indicators

📌 *Note:* This dataset is AI-generated for analytical and visualization practice while maintaining realistic structure and distributions.

## 🔍 Key Insights Generated

- High utilization clusters indicate infrastructure stress in specific states  
- Fast chargers contribute significantly but remain lower in share  
- Demand-heavy regions require expansion to reduce waiting time and overload  
- Utilization benchmarking helps prioritize investment decisions
