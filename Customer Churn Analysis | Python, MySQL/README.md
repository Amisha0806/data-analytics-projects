# 📊 Customer Churn Analysis Project 

## 🔍 Project Overview
Customer churn is one of the biggest challenges for subscription-based businesses.  
This project focuses on analyzing customer behavior to identify the key factors that lead to churn and provide actionable retention insights.

The complete analysis was performed using **Python in Jupyter Notebook**, following an end-to-end data analytics workflow.

---

## 🎯 Business Problem
Businesses lose revenue when customers discontinue services.  
The objective of this project is to:

- Understand churn patterns  
- Identify high-risk customer segments  
- Provide data-driven recommendations to improve retention  

---

## 🛠 Tools & Technologies Used
- Python (Pandas, NumPy)
- Matplotlib (Data Visualization)
- MySQL (Data Extraction)
- Jupyter Notebook

---

## 📌 Key Steps Performed
- Data Extraction from MySQL Database  
- Data Cleaning (Missing values, duplicates, outliers)  
- Feature Engineering (Tenure groups, inactivity flag, churn-risk segmentation)  
- KPI Analysis and Business Metrics  
- Advanced Visual Analysis (Heatmaps, Scatter, Boxplots, Trends, Funnel Views)  

---

## 📈 Key Insights
- Customers with **low tenure** churn more frequently  
- **Inactivity (login gap > 7 days)** is a strong churn indicator  
- Customers with **complaints** show higher churn probability  
- Regional churn differences highlight market-level challenges  
- Risk segmentation helps identify customers needing immediate retention focus  

---

## ✅ Business Recommendations
- Improve onboarding for new customers  
- Target inactive users with retention campaigns  
- Strengthen complaint resolution and support services  
- Focus on premium customer retention strategies  
- Use churn-risk segmentation for proactive action
