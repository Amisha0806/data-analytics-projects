# 🚨 UPI Fraud Monitoring & Risk Analytics Dashboard (Power BI)

## 📌 Project Overview
This project focuses on analyzing and monitoring **UPI-based digital payment fraud patterns** using a combination of **Python-generated transaction data** and an interactive **Power BI dashboard**.

The goal is to simulate a real-world fraud monitoring system used by fintech companies and banks to:

- Detect suspicious transaction behavior  
- Track high-risk users and merchants  
- Monitor fraud trends across cities, devices, and time periods  
- Support fraud investigation through risk analytics  

---

## 🎯 Key Objectives
- Build an end-to-end fraud analytics project using structured transaction data  
- Create a multi-page Power BI dashboard with investigation-level insights  
- Identify fraud drivers such as device type, failed attempts, amount bucket, and peak hours  
- Present recruiter-ready KPIs and fraud monitoring visuals  

---

## 🗂 Dataset Information
Since real UPI fraud datasets are not publicly available due to privacy reasons, this project uses **AI-generated synthetic transaction data** designed to closely match real banking transaction patterns.

### Dataset Features Include:
- Transaction Amount  
- Fraud Flag (Fraud / Genuine)  
- City-wise transactions  
- Merchant Categories  
- Device Type (Android, iOS, Web)  
- Risk Score (0–100)  
- Failed Login Attempts  
- Transaction Hour  
- Risk Segment (Low / Medium / High)
